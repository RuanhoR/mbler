# v0.3.0 (2026-08-28)

### Highlights

First minor release of the 0.3.x line — headlined by in-game live reload over WebSocket (`devWs`), two new commands (`sync-mc-dep`, `cache`), `.brarchive` sub-directory packaging, and a `minify: 'none'` option to disable script minification.

### Features

- **In-game live reload**: New `devWs` / `devWsPort` config options start a WebSocket server that pushes `/reload` to the game on rebuild — scripts via `/reload`, resources via `/reload all` (`5ce013c`, `a92b216`, `7fd7ecb`, `e36a8c2`, `1327d97`)
- **`sync-mc-dep` command**: Sync SAPI versions for dependencies (`f4d8f70`)
- **`cache` command**: sapi_version refresh/clear/list with 5-day cache expiry (`560c152`)
- **`.brarchive` packaging**: Pack output sub-directories into `.brarchive` archives (`0ea06d3`)
- **`minify: 'none'`**: New minify option to disable script minification (`9ec9607`)
- **`otherDeps`**: Extra manifest dependencies from `mbler.config.js` (`1c9c1ab`)
- **`outGameOnDev`**: Output directly to game development packs (`b819a8f`)
- **Build cache**: Implemented build cache; removed `name`/`version` from mbler config (`291398a`)
- **Config validation**: Validate required fields in `ReadProjectMblerConfig` (`979140c`)

### Fixes

- **Profile**: Resolved libuv assertion on process exit (Windows); multi-line text input via Ctrl+Enter submit; natural event-loop drain instead of `process.exit()` (`7e5a519`)
- **Input UI**: Multi-line frames fully cleared in `Input.select`; enter submits and wrapped rows clear (`2cea411`, `d1fd734`)
- **Spawn**: Reject unsafe cmd metacharacters in win32 shell; hardened URL encoding (`db0dba0`, `522d63d`)
- **Watch mode**: Scoped watcher with file-type validation, add/addDir events, debounce + serialize file processing, ignore `.git`, clean before copy, config loaded via `ReadProjectMblerConfig` (`c850609`, `1aaead4`, `69dd3b2`, `a48d38d`, `1d61c20`, `1e84598`, `b4a77b4`)
- **Build**: `ensureLanguagesJson` for auto language.json generation; subpacks allow list; strip `-beta` suffix from Sapi version when `isBeta=false` (`fd8ed78`, `730b578`, `267f623`)
- **CLI**: Strip all leading dashes in option parsing; persist new version to package.json (`138e937`, `55538e5`)
- **Windows**: `pathToFileURL` / forward-slash normalization for dynamic imports; config import path fix (`ca1abaf`, `950c10c`, `1baf950`, `16d7601`)
