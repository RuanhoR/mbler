# MBLER — Agent Guide

MCX DSL CLI tool for Minecraft Bedrock Edition addon development. Single package (no workspace). pnpm, ESM, Node >=20.

## Layout

```
bin/                    # CLI entry points (mbler.cjs → dist/index.mjs)
src/
  cli/                  # Command definitions & dispatcher (init/build/watch/publish/install/...)
  build/                # Build engine (Rolldown-based): archive, cache, config, manifest, minify, progress, release, sapi
  commander/            # Declarative command framework (CommandDef, parseArgs)
  i18n/                 # en / zh translations
  logger/               # Logger
  publisher/            # PMNX marketplace: configManager, GamePath, installManager, publishManager, tokenManager
  utils/                # defineConfig, file helpers
  config.ts             # mbler.config.js loading
  types.ts              # MblerConfigData, MblerBuildConfig, ManifestData
  version.ts            # GENERATED by scripts/gen-version.mjs (pretest) — do not edit
tests/                  # vitest specs (mirror src/)
dist/                   # rolldown output (index.mjs + build.mjs + d.ts)
```

## Commands (run from repo root)

```bash
pnpm install            # also installs git hooks (simple-git-hooks)
pnpm build              # rolldown -c
pnpm test               # pretest (gen:version) + vitest run
pnpm lint               # eslint src/
pnpm type-check         # tsc --noEmit
pnpm check              # gen:version + lint + test + type-check
pnpm format             # prettier ./src ./example --write
pnpm gen:version        # regenerates src/version.ts from package.json + git log
```

`pnpm test` requires `src/version.ts`, which `pretest` regenerates — don't delete it.

## Gotchas an agent will miss

- **Commit messages are enforced** by `scripts/verify-commit.mjs` (commit-msg hook): must match `^(revert: )?(feat|fix|docs|dx|style|refactor|perf|test|workflow|build|ci|chore|types|wip|release)(\(.+\))?: .{1,50}`. Wrong format aborts the commit.
- **ESLint is stricter than mcx-core**: `@typescript-eslint/no-explicit-any: error`, `no-unused-vars: error` (with `^_` ignore patterns), `no-require-imports: off`, `no-console: off`.
- **Prettier config** (`.prettierrc`): `semi: false`, `singleQuote: true`, `tabWidth: 2`, `trailingComma: 'es5'`. Note: this differs from mcx-core (which uses `semi: true`).
- **`rolldown.config.mjs` generates `src/version.ts` at build time** (writes git commit + version) and externals all `dependencies`, `@mbler/*`, and `typescript/*` — the build entry for `mbler/build` is `src/index.build.ts`.
- **`src/version.d.ts`** provides the type for the generated `version.ts` — keep it if you add fields.
- **No comments / no console.log in production code** (convention, not lint-enforced).

## Architecture notes

- `mbler` no longer ships the `mcx-tsc` type-checker — it was split out to the `mcx-tsc` package in `mcx-core` (same repo family). Generated projects get `mcx-tsc` from `create-mbler`'s devDependencies.
- `mbler/build` subpath export (`./build`) maps to `src/index.build.ts` and is what CLI commands import lazily.
- Build pipeline: read `mbler.config.js` → Rolldown with `@mbler/mcx-core`'s `rolldownPlugin` (when `script.lang == 'mcx'`) → generate `manifest.json` → (release) package `.mcaddon` / `.brarchive`.
- `typescript` is a **peerDependency** (used via `await import('typescript')` inside the build flow), not a direct dependency.

## Publishing

Publish with `pnpm publish --tag latest`. Version scheme: `0.2.x` releases and `0.2.x-rc.Y` RCs (e.g. `0.2.12-rc.1`). Bump `package.json` version, regenerate `src/version.ts` (`pnpm gen:version`) before building/publishing.
